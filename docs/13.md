## تمام — نضيف “آخر رسالة + عداد غير مقروء” في الـSidebar مثل واتساب

سننفّذها **عميل-فقط** (بدون أي تعديل على السيرفر) عبر:
- Model جديد `UserItem` يحفظ:
    - `username`
    - `lastPreview` (آخر رسالة/ملف)
    - `unreadCount`
- عند وصول `INCOMING_TEXT` أو `INCOMING_FILE`:
    - لو المحادثة **غير مفتوحة** ⇒ `unreadCount++`
    - تحديث `lastPreview`
- عند فتح محادثة (اختيار مستخدم):
    - `unreadCount = 0`
    - عمل `requestThread(peer)`
- عند وصول thread كامل: نحدّث `lastPreview` من آخر عنصر

# 1) أضف Model: `UserItem`

**Create file:** `src/main/java/com/hamza/filetransfer/client/UserItem.java`
```java
package com.hamza.filetransfer.client;

import javafx.beans.property.*;

public class UserItem {
    private final StringProperty username = new SimpleStringProperty();
    private final StringProperty lastPreview = new SimpleStringProperty("");
    private final IntegerProperty unreadCount = new SimpleIntegerProperty(0);

    public UserItem(String username) {
        this.username.set(username);
    }

    public StringProperty usernameProperty() { return username; }
    public StringProperty lastPreviewProperty() { return lastPreview; }
    public IntegerProperty unreadCountProperty() { return unreadCount; }

    public String getUsername() { return username.get(); }

    public void bumpUnread() { unreadCount.set(unreadCount.get() + 1); }
    public void clearUnread() { unreadCount.set(0); }

    public void setLastPreview(String preview) {
        lastPreview.set(preview == null ? "" : preview);
    }
}
```

    private void applyUsers(List<String> usernames) {
        // نحدّث القائمة بدون ما نخسر unread/preview الموجودة
        for (String u : usernames) {
            userIndex.computeIfAbsent(u, key -> {
                UserItem item = new UserItem(key);
                userItems.add(item);
                return item;
            });
        }
        // إزالة من خرج من Online (اختياري):
        userItems.removeIf(item -> !usernames.contains(item.getUsername()));
        userIndex.keySet().retainAll(usernames);
    }

    private void bumpUnreadAndPreview(String fromUser, String preview) {
        UserItem item = userIndex.get(fromUser);
        if (item == null) return;

        item.setLastPreview(preview);

        // لو المحادثة ليست مفتوحة -> زود العداد
        if (activePeer == null || !activePeer.equals(fromUser)) {
            item.bumpUnread();
        }
    }

    private void clearUnread(String user) {
        UserItem item = userIndex.get(user);
        if (item != null) item.clearUnread();
    }

    private void updateLastPreviewFromThread(String peer, List<ChatMessage> msgs) {
        if (peer == null) return;
        UserItem item = userIndex.get(peer);
        if (item == null || msgs == null || msgs.isEmpty()) return;

        ChatMessage last = msgs.get(msgs.size() - 1);
        String preview;
        if (last.typeProperty().get() == ChatMessage.Type.TEXT) {
            String t = last.textProperty().get();
            preview = (t == null) ? "" : t;
            if (preview.length() > 40) preview = preview.substring(0, 40) + "...";
        } else {
            preview = "\uD83D\uDCCE " + last.fileNameProperty().get();
        }
        item.setLastPreview(preview);
    }

    private static final class UserCell extends ListCell<UserItem> {
        @Override
        protected void updateItem(UserItem item, boolean empty) {
            super.updateItem(item, empty);

            if (empty || item == null) {
                setGraphic(null);
                setText(null);
                return;
            }

            Label name = new Label(item.getUsername());
            name.getStyleClass().add("user-name");

            Label preview = new Label();
            preview.textProperty().bind(item.lastPreviewProperty());
            preview.getStyleClass().add("user-preview");

            VBox textBox = new VBox(2, name, preview);

            Label badge = new Label();
            badge.getStyleClass().add("badge");
            badge.textProperty().bind(item.unreadCountProperty().asString());
            badge.visibleProperty().bind(item.unreadCountProperty().greaterThan(0));
            badge.managedProperty().bind(badge.visibleProperty());

            HBox row = new HBox(10, textBox, new Region(), badge);
            HBox.setHgrow(row.getChildren().get(1), Priority.ALWAYS);
            row.setAlignment(Pos.CENTER_LEFT);
            row.getStyleClass().add("user-row");

            setGraphic(row);
        }
    }
