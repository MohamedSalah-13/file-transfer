## ممتاز — Offline + حد 200MB (تصميم شبه واتساب “Direct to user via server”)

سنبني نظامًا كالتالي:

- **اتصال دائم لكل عميل مع السيرفر** (Socket واحد) لاستقبال:
    - إشعارات فورية `INCOMING_FILE` عندما يكون المستقبل Online
    - ردود الأوامر (قائمة المستخدمين/ملفاتي…)
- عند إرسال ملف من A إلى B:
    - السيرفر **يستقبل الملف كاملًا** (Streaming) ويخزّنه داخل **Inbox** الخاص بـ B
    - إذا كان B Online: السيرفر يرسل له إشعارًا فوريًا بوجود ملف جديد
    - إذا كان B Offline: الملف يبقى في Inbox، وسيظهر لـ B عند تسجيل الدخول وعمل `LIST_MY_FILES`
- **حد أقصى 200MB**: السيرفر يرفض أي ملف أكبر (قبل استقبال البايتات).

---

## 1) هيكلة التخزين على السيرفر (كل عميل يرى ملفاته فقط)

على السيرفر:
```
server-storage/
  users/
    <username>/
      inbox/
        <fileId>.meta
        <fileId>.bin
      sent/   (اختياري)
```


- `*.bin` محتوى الملف (Bytes)
- `*.meta` بيانات الملف (JSON أو Properties) مثل:
    - fromUser, toUser, originalName, size, timestamp, status

> هذا يمنع أي عميل من رؤية ملفات غيره لأن السيرفر لن يسمح إلا بـ `LIST/DOWNLOAD` داخل مجلد username المصادق عليه.

---

## 2) البروتوكول (رسائل بسيطة وواضحة)

سنستخدم `DataInputStream/DataOutputStream`.

### Constants
- `MAX_FILE_BYTES = 200 * 1024 * 1024` (200MB)

### أوامر (Client → Server)
- `HELLO username`
- `LIST_USERS`
- `SEND_FILE toUser fileName fileSize` ثم bytes
- `LIST_MY_FILES`
- `DOWNLOAD fileId`

### ردود/إشعارات (Server → Client)
- `HELLO_OK | HELLO_TAKEN`
- `USERS count {user...}`
- `SEND_OK fileId` أو `ERROR message`
- `MY_FILES count {fileId, fileName, size, fromUser, timestamp}`
- `FILE fileName fileSize` ثم bytes
- **إشعار فوري**: `INCOMING_FILE fileId fromUser fileName fileSize timestamp`

---

## 3) التزامن: كيف نضمن إشعارات فورية + أوامر

### على السيرفر
- عند اتصال عميل:
    - نسجل `username -> ClientConnection` داخل `ConcurrentHashMap`
    - `ClientConnection` يحتوي `DataOutputStream` + Lock للكتابة (حتى لا تتداخل الرسائل)

### على العميل
- Thread واحد يقرأ باستمرار من السيرفر ويُمرر الرسائل إلى UI (JavaFX) عبر:
    - `Platform.runLater(...)`
    - أو `Task`/`Service` حسب ما تفضله

## 4) فرض حد 200MB (مهم)

عند استقبال `SEND_FILE`:
1) اقرأ `fileSize`
2) إذا `fileSize > MAX_FILE_BYTES`:
    - أرسل `ERROR "File too large (max 200MB)"`
    - **لا تستقبل bytes**
    - أغلق العملية/أو تجاهلها حسب بروتوكولك (الأفضل: أغلق الاتصال لتجنب desync)

> أيضًا على العميل، قبل الإرسال، افحص الحجم محليًا لتجنب تضييع وقت المستخدم.

## 5) نموذج “كائنات” أساسية (لـ UI والسيرفر)

### TransferSession (لإظهار Progress على السيرفر والعميل)
- id
- fromUser

- fileName

### FileRecord (لـ LIST_MY_FILES)

## 7) كود مهم (أمثلة مركّزة)

### 7.1 ثابت الحد 200MB
```java
public final class Limits {
    public static final long MAX_FILE_BYTES = 200L * 1024 * 1024; // 200MB
    private Limits() {}
}
```


### 7.2 التحقق قبل الإرسال (Client)
```java
import java.nio.file.Files;
import java.nio.file.Path;

public final class ClientValidation {
    public static void ensureAllowedSize(Path file) throws Exception {
        long size = Files.size(file);
        if (size > Limits.MAX_FILE_BYTES) {
            throw new IllegalArgumentException("File exceeds 200MB limit.");
        }
    }
}
```


### 7.3 استقبال SEND_FILE على السيرفر (Streaming + Meta + إشعار)
> هذا مثال “فكرة التنفيذ” (ليس كامل كل التفاصيل)، لكنه يوضح النقاط الحساسة: size limit + storage + notify.

```java
import java.io.*;
import java.nio.file.*;
import java.time.Instant;
import java.util.UUID;

public class SendFileHandler {

    private final Path baseDir; // server-storage/users
    private final OnlineUsersRegistry onlineUsers;

    public SendFileHandler(Path baseDir, OnlineUsersRegistry onlineUsers) {
        this.baseDir = baseDir;
        this.onlineUsers = onlineUsers;
    }

    public void handle(String fromUser, DataInputStream in, DataOutputStream out) throws Exception {
        String toUser = in.readUTF();
        String fileName = in.readUTF();
        long fileSize = in.readLong();

        if (fileSize < 0 || fileSize > Limits.MAX_FILE_BYTES) {
            out.writeUTF("ERROR");
            out.writeUTF("File too large. Max is 200MB.");
            out.flush();
            return;
        }

        String fileId = UUID.randomUUID().toString();
        Instant ts = Instant.now();

        Path userDir = baseDir.resolve(toUser).resolve("inbox");
        Files.createDirectories(userDir);

        Path bin = userDir.resolve(fileId + ".bin");
        Path meta = userDir.resolve(fileId + ".meta");

        // اكتب البيانات (Streaming)
        try (OutputStream fileOut = Files.newOutputStream(bin, StandardOpenOption.CREATE_NEW)) {
            byte[] buffer = new byte[64 * 1024];
            long received = 0;
            while (received < fileSize) {
                int toRead = (int) Math.min(buffer.length, fileSize - received);
                int read = in.read(buffer, 0, toRead);
                if (read == -1) throw new EOFException("Client disconnected during upload");
                fileOut.write(buffer, 0, read);
                received += read;

                // هنا تحدّث Progress في Server UI عبر TransferSession
            }
        }

        // اكتب meta (بشكل بسيط Properties مثلاً)
        String metaContent =
                "fileId=" + fileId + "\n" +
                "fromUser=" + fromUser + "\n" +
                "toUser=" + toUser + "\n" +
                "fileName=" + fileName + "\n" +
                "fileSize=" + fileSize + "\n" +
                "timestamp=" + ts + "\n";
        Files.writeString(meta, metaContent, StandardOpenOption.CREATE_NEW);

        // رد للمرسل
        out.writeUTF("SEND_OK");
        out.writeUTF(fileId);
        out.flush();

        // إشعار للمستلم إذا Online
        ClientConnection toConn = onlineUsers.get(toUser);
        if (toConn != null) {
            toConn.sendIncomingFile(fileId, fromUser, fileName, fileSize, ts.toString());
        }
    }
}
```


وواجهة إرسال الإشعار:
```java
import java.io.DataOutputStream;

public class ClientConnection {
    private final DataOutputStream out;
    private final Object writeLock = new Object();

    public ClientConnection(DataOutputStream out) {
        this.out = out;
    }

    public void sendIncomingFile(String fileId, String fromUser, String fileName, long size, String timestamp) throws Exception {
        synchronized (writeLock) {
            out.writeUTF("INCOMING_FILE");
            out.writeUTF(fileId);
            out.writeUTF(fromUser);
            out.writeUTF(fileName);
            out.writeLong(size);
            out.writeUTF(timestamp);
            out.flush();
        }
    }
}
```

## 8) نقطة أمن/منع رؤية ملفات غيرك (Rule بسيطة لكن حاسمة)

في `DOWNLOAD fileId`:
- السيرفر يعرف `username` من جلسة الاتصال (بعد `HELLO`)
- لا يسمح بالتحميل إلا إذا كان الملف موجودًا داخل:
    - `server-storage/users/<thisUsername>/inbox/<fileId>.*`
- غير ذلك: `ERROR "Not found"`
