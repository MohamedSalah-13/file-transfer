## تمام — نضيف `INCOMING_TEXT` (إشعار مستقل ونظيف)

سنعمل 3 تعديلات:
1) `Protocol`: إضافة `INCOMING_TEXT`
2) `FileTransferServer`: عند `SEND_TEXT` يرسل `INCOMING_TEXT` للمستلم إن كان Online
3) `ClientConnection`: يستقبل `INCOMING_TEXT` ويستدعي callback `onIncomingText`
4) `ClientApp`: عند وصول `INCOMING_TEXT`، لو أنت فاتح نفس المحادثة، يعمل `requestThread(peer)` لتحديثها فورًا

```java
    private void handleSendText(String fromUser, DataInputStream in, DataOutputStream out, Object lock) throws Exception {
        String toUser = in.readUTF().trim();
        String text = in.readUTF();

        if (text == null) text = "";
        text = text.trim();
        if (text.isEmpty()) {
            sendError(out, lock, "Empty text");
            return;
        }
        if (text.length() > 2000) {
            sendError(out, lock, "Text too long (max 2000 chars)");
            return;
        }

        String messageId = UUID.randomUUID().toString();
        Instant ts = Instant.now();
        long epochMillis = ts.toEpochMilli();

        writeThreadMetaText(toUser, fromUser, messageId, "IN", fromUser, toUser, text, ts.toString(), epochMillis);
        writeThreadMetaText(fromUser, toUser, messageId, "OUT", fromUser, toUser, text, ts.toString(), epochMillis);

        synchronized (lock) {
            out.writeUTF(Protocol.SEND_OK);
            out.writeUTF(messageId);
            out.flush();
        }

        OnlineClient targetControl = online.get(toUser);
        if (targetControl != null) {
            synchronized (targetControl.lock()) {
                targetControl.out().writeUTF(Protocol.INCOMING_TEXT);
                targetControl.out().writeUTF(messageId);
                targetControl.out().writeUTF(fromUser);
                targetControl.out().writeUTF(ts.toString());
                targetControl.out().flush();
            }
        }
    }
```

# 3) ClientConnection.java: استقبال INCOMING_TEXT + callback

```java
package com.hamza.filetransfer.client;

// ... existing imports ...
import java.util.function.Consumer;

public class ClientConnection implements Closeable {

    // ... existing code ...

    private Consumer<IncomingTextEvent> onIncomingText = evt -> {};

    public record IncomingTextEvent(String messageId, String fromUser, String timestamp) {}

    public void setOnIncomingText(Consumer<IncomingTextEvent> onIncomingText) {
        this.onIncomingText = onIncomingText;
    }

    private void listenLoop() {
        try {
            while (running) {
                String type = in.readUTF();

                if (Protocol.ERROR.equals(type)) {
                    String msg = in.readUTF();
                    Platform.runLater(() -> onError.accept(msg));

                } else if (Protocol.USERS.equals(type)) {
                    // ... existing code ...

                } else if (Protocol.MY_FILES.equals(type)) {
                    // ... existing code ...

                } else if (Protocol.THREAD_MESSAGES.equals(type)) {
                    // ... existing code ...

                } else if (Protocol.INCOMING_FILE.equals(type)) {
                    String fileId = in.readUTF();
                    String fromUser = in.readUTF();
                    String fileName = in.readUTF();
                    long size = in.readLong();
                    String ts = in.readUTF();
                    InboxFile f = new InboxFile(fileId, fileName, size, fromUser, ts);
                    Platform.runLater(() -> onIncoming.accept(f));

                } else if (Protocol.INCOMING_TEXT.equals(type)) {
                    String messageId = in.readUTF();
                    String fromUser = in.readUTF();
                    String ts = in.readUTF();
                    IncomingTextEvent evt = new IncomingTextEvent(messageId, fromUser, ts);
                    Platform.runLater(() -> onIncomingText.accept(evt));

                } else if (Protocol.SEND_OK.equals(type)) {
                    String messageId = in.readUTF();

                } else {
                    Platform.runLater(() -> onError.accept("Unknown server message: " + type));
                }
            }
        } catch (EOFException ignored) {
            if (running) Platform.runLater(() -> onError.accept("Disconnected"));
        } catch (Exception e) {
            if (running) Platform.runLater(() -> onError.accept("Disconnected: " + e.getMessage()));
        }
    }

    // ... existing code ...
}
```

أضف داخل connect handler بعد إنشاء `conn`:

```java

conn.setOnIncomingText(evt -> {
    // إذا أنت فاتح محادثة مع نفس الشخص، حدثها فوراً
    if (activePeer != null && activePeer.equals(evt.fromUser())) {
        try {
            conn.requestThread(activePeer);
        } catch (Exception ignored) {}
    }
});
```


> تقدر أيضًا تعمل “badge” على المستخدم في القائمة لو الرسالة جاءت من شخص غير مفتوح الآن (مثل واتساب). إذا تحب، أضيفها لك بخطوة لاحقة.

## ملحوظة صغيرة
حاليًا ما زلنا نستخدم `INCOMING_FILE` للملفات (ممتاز) و`INCOMING_TEXT` للنصوص (أنظف).  
وبكذا واجهة الشات ستتحدّث تلقائيًا لما توصل رسالة جديدة.

إذا تريد “واتساب كامل”: الخطوة التالية تكون **آخر رسالة + عداد غير مقروء** لكل مستخدم في الـSidebar.
