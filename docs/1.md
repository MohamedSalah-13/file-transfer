## فكرة المشروع (مثل واتساب لكن لنقل الملفات)

ستبني **تطبيقين JavaFX**:

1) **Server App (واجهة سيرفر)**
- يعرض قائمة التحميلات/الرفع الجارية (Sessions)
- لكل ملف: اسم الملف، اسم العميل، الحجم، السرعة/الحالة، **ProgressBar**

2) **Client App (واجهة عميل)**
- يعرض الملفات التي رفعها العميل (أو الملفات المتاحة على السيرفر)
- عند الضغط على ملف ⇒ **Download**
- لكل عملية رفع/تنزيل: **ProgressBar** + حالة

---

## تصميم معماري مناسب (بسيط وقابل للتطوير)

### 1) طبقة الشبكة (Networking)
- استخدم `ServerSocket` / `Socket` (TCP) لنقل البيانات بثبات.
- نفّذ بروتوكول بسيط “رسائل + بيانات”:
    - رسائل أوامر (JSON أو نص) عبر `DataInputStream/DataOutputStream`
    - ثم بث الملف كـ bytes

> إذا تريد “قائمة ملفات على السيرفر” و “ضغط على ملف لتنزيله”، فالأفضل أن يكون السيرفر هو المصدر الحقيقي للملفات.

---

## البروتوكول المقترح (سهل جداً)

كل عملية تبدأ برسالة أمر:

- **UPLOAD**
    - يرسل العميل:
        - `command = "UPLOAD"`
        - `fileName`
        - `fileSize`
    - ثم يرسل bytes الملف
    - السيرفر يحفظ الملف في مجلد مثل `server-storage/`

- **LIST**
    - العميل يرسل:
        - `command = "LIST"`
    - السيرفر يرد بقائمة ملفات (أسماء + أحجام)

- **DOWNLOAD**
    - العميل يرسل:
        - `command = "DOWNLOAD"`
        - `fileName`
    - السيرفر يرد:
        - `fileSize`
        - ثم bytes الملف

---

## كيف نعمل Progress في JavaFX (النقطة الأهم)

### الفكرة
أنت تقرأ/تكتب الملف على شكل chunks (مثلاً 64KB)، وتجمع `bytesTransferred`، ثم:

```java
double progress = (double) bytesTransferred / fileSize;
```


وفي JavaFX لا تحدّث UI من Thread الشبكة مباشرة، بل:
- إما `Platform.runLater(...)`
- أو الأفضل: استخدم `Task<Void>` واربط `progressProperty()` مع ProgressBar

## نموذج كود: نقل ملف مع Progress (مشترك للفكرتين)

### رفع (Client → Server) مع Progress
```java
import javafx.concurrent.Task;

import java.io.*;
import java.net.Socket;
import java.nio.file.Files;
import java.nio.file.Path;

public class UploadTask extends Task<Void> {
    private final String host;
    private final int port;
    private final Path file;

    public UploadTask(String host, int port, Path file) {
        this.host = host;
        this.port = port;
        this.file = file;
    }

    @Override
    protected Void call() throws Exception {
        long fileSize = Files.size(file);
        String fileName = file.getFileName().toString();

        try (Socket socket = new Socket(host, port);
             DataOutputStream out = new DataOutputStream(new BufferedOutputStream(socket.getOutputStream()));
             DataInputStream in = new DataInputStream(new BufferedInputStream(socket.getInputStream()));
             InputStream fileIn = Files.newInputStream(file)) {

            // 1) إرسال الأمر + ميتاداتا
            out.writeUTF("UPLOAD");
            out.writeUTF(fileName);
            out.writeLong(fileSize);
            out.flush();

            // 2) إرسال البيانات مع progress
            byte[] buffer = new byte[64 * 1024];
            long sent = 0;
            int read;
            while ((read = fileIn.read(buffer)) != -1) {
                out.write(buffer, 0, read);
                sent += read;

                updateProgress(sent, fileSize);
                updateMessage("Uploading " + fileName + " (" + sent + "/" + fileSize + ")");
                if (isCancelled()) break;
            }
            out.flush();

            // (اختياري) تأكيد من السيرفر
            String ack = in.readUTF(); // مثلاً: "OK"
            updateMessage(ack);
        }
        return null;
    }
}
```

## نموذج كود: السيرفر يستقبل UPLOAD ويحدّث Progress (داخل السيرفر)

الفكرة: لكل عميل Thread/Task. على السيرفر UI تعرض جدول Sessions.
على مستوى “Engine” في السيرفر، خزّن جلسة فيها `progressProperty`.

**مثال استقبال (بدون UI الآن):**
```java
import java.io.*;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.file.*;

public class FileServer {
    private final int port;
    private final Path storageDir = Path.of("server-storage");

    public FileServer(int port) {
        this.port = port;
    }

    public void start() throws IOException {
        Files.createDirectories(storageDir);

        try (ServerSocket serverSocket = new ServerSocket(port)) {
            while (true) {
                Socket client = serverSocket.accept();
                new Thread(() -> handleClient(client)).start();
            }
        }
    }

    private void handleClient(Socket client) {
        try (client;
             DataInputStream in = new DataInputStream(new BufferedInputStream(client.getInputStream()));
             DataOutputStream out = new DataOutputStream(new BufferedOutputStream(client.getOutputStream()))) {

            String cmd = in.readUTF();

            if ("UPLOAD".equals(cmd)) {
                String fileName = in.readUTF();
                long fileSize = in.readLong();

                Path target = storageDir.resolve(fileName);
                try (OutputStream fileOut = Files.newOutputStream(target, StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING)) {
                    byte[] buffer = new byte[64 * 1024];
                    long received = 0;

                    while (received < fileSize) {
                        int toRead = (int) Math.min(buffer.length, fileSize - received);
                        int read = in.read(buffer, 0, toRead);
                        if (read == -1) break;
                        fileOut.write(buffer, 0, read);
                        received += read;

                        // هنا تحسب progress وتبعثه للـ UI (سأشرحها تحت)
                        double progress = (double) received / fileSize;
                        // updateSessionProgress(fileName, progress, received, fileSize);
                    }
                }

                out.writeUTF("OK");
                out.flush();
            }

            // لاحقاً: LIST / DOWNLOAD

        } catch (Exception e) {
            // log
        }
    }

    public static void main(String[] args) throws IOException {
        new FileServer(5000).start();
    }
}
```

## شاشة السيرفر: جدول التحميلات (TableView)

### نموذج بيانات (Session)
- `fileName`
- `clientAddress`
- `direction` (UPLOAD/DOWNLOAD)
- `progressProperty` (DoubleProperty)
- `statusProperty` (StringProperty)

ثم في JavaFX:
- عمود اسم الملف
- عمود الحالة
- عمود ProgressBar عبر `TableCell` تعرض `ProgressBar` مربوط بـ progress

## شاشة العميل: قائمة ملفات على السيرفر + تنزيل عند الضغط

### الخطوات
1) زر “Refresh” يرسل `LIST`
2) يعرض `ListView` أو `TableView` للملفات
3) عند الضغط على ملف ⇒ يبدأ `DownloadTask` (Task مثل UploadTask لكن بالعكس)

## سؤالان مهمان قبل ما أرتب لك هيكل مشروع جاهز (Server + Client + UI)

1) هل تريد الملفات **تكون متاحة للجميع على السيرفر** (مثل “ملفات عامة”)؟  
   أم كل عميل يرى فقط ملفاته؟

2) هل تريد “واتساب مثل” بمعنى **إرسال مباشر لعميل محدد** (client-to-client عبر السيرفر)؟  
   أم فقط: **رفع إلى السيرفر** ثم أي عميل ينزل؟

إذا تجاوبني على هذين السؤالين، أعطيك:
- هيكل حزم (packages) واضح
- كود `LIST` و `DOWNLOAD` كامل
- نماذج JavaFX (TableView + ProgressBar cell) للسيرفر والعميل بشكل مرتب وقابل للتوسعة.
