## الجديد

- **نسخ Linux و macOS**: البرنامج بقى ليه ملفات تثبيت لـ Linux (`.deb`) و macOS (`.dmg`، لأجهزة Apple Silicon و Intel)، تحت في ملفات الإصدار ده. على Linux الملف فيه البرنامجين، وعلى macOS فيه ملف للعميل وملف للسيرفر.
  - Linux: `sudo apt install ./FileTransfer-3.0.1-linux-x64.deb`
  - macOS: افتح الـ `.dmg` واسحب التطبيق على Applications. التطبيق مش موقّع من Apple، فأول مرة افتحه بكليك يمين ← Open.
- **ملاحظات التحديث بقت أوضح**: من التحديث الجاي، "ما الجديد" بيظهر منسّق بعناوين وقوائم، مش نص خام.
- إعداد الإشعارات بقى اسمه "إشعار على سطح المكتب" بدل "إشعار من Windows".

## التحديث

## What's new

- **Linux and macOS versions**: the program now has installers for Linux (`.deb`) and macOS (`.dmg`, for Apple Silicon and Intel), in this release's files below. On Linux one package holds both programs; on macOS the client and the server each have their own file.
  - Linux: `sudo apt install ./FileTransfer-3.0.1-linux-x64.deb`
  - macOS: open the `.dmg` and drag the app to Applications. The app isn't signed by Apple, so open it the first time with right-click → Open.
- **Clearer update notes**: from the next update on, "What's new" shows formatted, with headings and lists instead of raw text.
- The notification setting now says "desktop notification" instead of "Windows notification".

## Updating

The server and the clients talk the same way as before: 3.0.1 works with 3.0.0 servers and clients, so update in any order.

On Linux and macOS the program tells you when a new release is out and opens its page; you install it yourself.

The Windows installer isn't code-signed, so Windows SmartScreen may warn on first run ("More info" → "Run anyway").
