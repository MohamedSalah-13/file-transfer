## ⚠️ اقرأ قبل التحديث

- **حدّث السيرفر الأول، وبعده العملاء.** 3.0 غيّر طريقة الكلام بين السيرفر والعميل: سيرفر 3.0 لا يقبل عملاء 2.x، وعميل 3.0 لا يتصل بسيرفر 2.x. العميل اللي يلاقي السيرفر أحدث منه بيعرض التحديث على طول.
- **اعمل نسخة احتياطية من فولدر بيانات السيرفر قبل التحديث** (`%USERPROFILE%\.file-transfer\server` للسيرفر المثبّت). أول تشغيل لسيرفر 3.0 بيشفّر الرسائل والملفات المحفوظة.
- **احتفظ بملف `keys\storage.key`** (جوه فولدر التخزين) في مكان آمن: هو مفتاح التشفير، ومن غيره الرسائل والملفات المحفوظة مش ممكن تتقري تاني.

## الجديد

- **حذف الرسائل**: كليك يمين على رسالة (أو زرار Delete) ← "حذف...". "حذف لدي" بيشيلها من محادثتك انت بس، و"حذف لدى الجميع" (لرسايلك انت بس) بيشيلها عند الطرفين ويسيب مكانها "تم حذف هذه الرسالة"، ولو كانت ملف بيتمسح من السيرفر.
- **تشفير التخزين على السيرفر**: كل الرسائل والملفات المحفوظة على السيرفر بقت مشفّرة (AES-256-GCM)، فنسخة من الفولدر من غير المفتاح ما تتقراش.
- **تحديثات أذكى**: العميل بيدوّر على تحديثه فورًا لو لقى السيرفر أحدث منه، والبرنامج بقى يفهم التحديثات الإجبارية في الإصدارات الجاية.

## ⚠️ Read before updating

- **Update the server first, then the clients.** 3.0 changed how the server and the clients talk: a 3.0 server refuses 2.x clients, and a 3.0 client can't connect to a 2.x server. A client that finds its server is newer offers its update right away.
- **Back up the server's data folder before updating** (`%USERPROFILE%\.file-transfer\server` for the installed server). The first start of a 3.0 server encrypts the stored messages and files.
- **Keep `keys\storage.key`** (inside the storage folder) somewhere safe: it is the encryption key, and without it the stored messages and files can't be read again.

## What's new

- **Delete messages**: right-click a message (or press Delete) → "Delete...". "Delete for me" removes it from your chat only; "Delete for everyone" (your own messages) removes it on both sides and leaves "This message was deleted", and a file is deleted from the server.
- **Encrypted storage on the server**: every stored message and file is encrypted (AES-256-GCM), so a copy of the folder is unreadable without the key.
- **Smarter updates**: a client looks for its update at once when its server is newer, and the program now understands required updates for future releases.

The installer isn't code-signed, so Windows SmartScreen may warn on first run ("More info" → "Run anyway").
